やることは 3 つだけです。ポートやプロキシなどの設定はすべて自動で行います。Windows の設定や証明書は変更しません。

        1. ブラウザの通信を記録する
        
    
        このツールが用意するプロキシ (中継サーバー) をブラウザに設定し、普段どおりにサイトを操作すると、やり取りされた HTTP 通信がすべて記録されます。別タブで開いた画面も同じプロキシを通るので、そのまま記録されます。
        
    すでに HAR ファイル (ブラウザの開発者ツールで保存した通信ログ) がある場合は、この手順を飛ばして「2 読み込み」へ進んでください。
        
  
        

  {% if not mitmproxy_available %}
  
        
    mitmproxy が見つかりません。 記録機能を使うには、コマンドプロンプト (ターミナル) で
    pip install "reqrec[record]" を実行し、GUI を再起動してください。HAR ファイルの読み込みはそのまま使えます。
  
        
  {% endif %}

  
        
    
        
      
        記録の設定
        
      
        
        
        
         通常は 8080 のままで構いません
        

        
        
        
          
        カンマ区切りで複数指定できます。サブドメインも含めて記録されます。空欄なら開いたサイトをすべて記録します。
        

        
        
         この PC のブラウザだけ使う場合は 127.0.0.1 のまま
        

        
        
        

        
        
        
          
          
        記録用のブラウザだけがこのツールのプロキシを通ります。Windows のプロキシ設定や証明書は変更しません。
        
        
        

        
        
        

        
        
        
          
          
        Edge の IE モードで表示が崩れないサイトは「既定」のままで構いません。既定以外は、この記録用ブラウザだけに効く設定をユーザーのレジストリ (HKCU) に書き込みます。選んだ表示モードは次回以降も (かんたん画面でも) そのまま使われます。

        ブラウザ側の手順
        
    
        記録方式が「アプリ内の記録用ブラウザで開く」のときは、下の手順は不要です。[記録開始] で開く記録用ブラウザ (タイトルに「記録中」と付いた窓) でサイトを操作してください。以下は「自分でブラウザを設定する」を選んだときの手順です。
        
    
          
      
        1. プロキシを設定する — ブラウザ (または Windows) の HTTP / HTTPS プロキシを 127.0.0.1:8080 にします。
        
            
          
          • Chrome / Edge を専用プロファイルで起動する例: chrome --proxy-server="127.0.0.1:8080" --user-data-dir=%TEMP%\reqrec-profile
            • 
          
          • Edge の IE モードは Windows の「インターネット オプション」(コントロール パネル → ネットワークとインターネット → インターネット オプション → 接続 → LAN の設定) のプロキシ設定を使います。Windows ではこの画面の「システムプロキシを自動で設定する」にチェックを入れると自動で設定・復元します。
            • 
        
          
      
          2. 
      
        2. CA 証明書を一度だけ登録する — HTTPS サイトを記録するために必要です。記録開始後、プロキシ経由で http://mitm.it を開いて自分の OS 用の証明書をダウンロードするか、~/.mitmproxy/mitmproxy-ca-cert.pem (Windows なら %USERPROFILE%\.mitmproxy\mitmproxy-ca-cert.cer) を「信頼されたルート証明機関」に登録します。Windows では下の「CA 証明書をインストール」ボタンで登録できます。
          3. 
      
        3. 記録したい操作を行う — ログイン → 一覧を開く → 詳細を見る、のように取得したい結果まで普段どおりに操作します。レスポンスを受け取るたびに自動保存されます。
          4. 
      
        4. [記録停止して読み込む] を押すと、記録が読み込まれて「3 ステップ」へ進みます。
